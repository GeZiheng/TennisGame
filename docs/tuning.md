# 调参不变量与踩过的坑

> 原为 `AGENTS.md` 第 5、6 节，2026-11-09 拆分独立成篇。**改任何常量之前先读这里**。
>
> 这些数不是拍脑袋定的，每一条都对应一类真实故障。踩过的坑按「几何/物理」「位姿时序」「测试」「工具链」「前端」分组，
> 每条都写过一次 bug、修过一次，重踩的成本以小时计。

## 5.1 场地与判定

| 常量 | 现值 | 不变量 |
|---|---|---|
| `HIT_Z` | 0.3 | 击球平面。`RACKET_POS.z` 与它对齐，否则「球在拍前 30cm 被打中」 |
| `RACKET_POS` | (0, 1.3, 0.3) | **握点**（胸口中线）。拍面中心在它沿拍柄 `FACE_CY` 处：竖握 1.9m、横握 1.3m。自动走位会把握点在 0.70–1.65 之间升降，所以拍面实际可及 0.70–2.25（横握）/ 1.30–2.25（竖握）。改它 = 同时改喂球高度、回球机 `ARRIVE_Y`、自动走位目标 |
| `FACE_RX` / `FACE_RY` | 0.15 / 0.19 | 直接决定可击面积。改大 = 变简单，会连带改喂球散布上限 |
| `FACE_CY` | 0.6 | 握点到拍面中心。改它会同时改拍面高度、glb 缩放、回球归一位姿 |
| `FACE_MARGIN` | 0.02 | 补位姿延迟（20–60ms）。低于 0.015 会「视觉上蹭到框、判定说没有」 |
| `BALL_R` | 0.0335 | 判定膨胀量。渲染用 `BALL_RENDER_R=0.057`（放大 1.7 倍，否则远处只有 5 像素） |
| `NET_Z` / `NET_H` | -10.5 / 0.914 | 网。撞网判定用「跨越平面」，不是距离 |
| `WALL_Z` / `WALL_H` | -11.9 / 5.2 | 墙。再远 2m 球撞完回不来；墙高是回球补偿的上限 |

## 5.2 球速与出球

| 常量 | 现值 | 不变量 |
|---|---|---|
| `SPEED_MIN` | **18** | **物理底线**。13–16 实测全挂：回球擦网或中场趴下。想更慢只能改墙弹性/墙距 |
| `SPEED_MAX` | 32 | 原来 42，球 0.3 秒到墙，玩家只看到一道黄影 |
| `SPEED_GAIN` | 2.4 | 手机测到的拍头速度只有真实的 1/2.4 |
| `SWING_ARM` | 0.68 | 等效力臂。与 `SPEED_GAIN` 的乘积决定手感，别单独动 |
| `FALL_RATIO` | **0.9** | 结算时机。0.75 → 峰值后 50–90ms（能感觉到黏）；1.0 → 平台段永不结算 |
| `SWING_THRESHOLD` | 3.0 | 差分会削峰值 15–25%，3.6 会漏检 |
| `SWING_MAX_MS` | 450 | 超过它是「转」不是「挥」 |

## 5.3 喂球与重瞄

| 常量 | 现值 | 不变量 |
|---|---|---|
| `FEED_APEX_LEAD` | **2.40** | 顶点在落点前方多远。**实测值**，偏 0.1m 顶点整体移 0.1m。改完必须重测 |
| `FEED_APEX_BACK_MIN/MAX` | 0.55 / 0.85 | 顶点在拍面之后多远。落点 = 2.40 − back = 1.55–1.85m |
| `FEED_APEX_DX/DY` | **0.12 / 0.10** | 顶点散布。两轴同时偏，合成 0.72；0.16/0.14 合成 0.98 会偶发判空 |
| 落地重瞄横向上限 | 1.6 m/s | 2 米飞行约 20cm。**别调大**：球会在落地瞬间明显横挪，等于把「追踪弹」加回来 |
| `RETURN_OFF_TOL` | 0.55 | 回球合格池的偏离上限。调到 0.9 以上会「擦着框回来」 |

## 5.4 时序

| 常量 | 现值 | 不变量 |
|---|---|---|
| `HIT_WINDOW_MS` | 150 | 时间窗只回答「算不算你挥的」，不决定几何命中 |
| `CONTACT_HOLD_MS` | **100** | 覆盖「结算 16–33ms + 网络 20–60ms」。60 会把最晚到达的挥拍误判成漏接 |
| `RESERVE_DELAY_MS` | 1300 | 断球后重新喂球。静止画面比瞬间重置容易接受 |
| `PHYS_DT` | 1/240 | 40 m/s 每步 16.7cm，不会隧穿 |
| `RacketTrack.keepMs` | 400 | 覆盖「球早到 150ms」和「挥晚 150ms」两头 |

## 5.5 自动走位（`AUTO_MOVE_DEFAULTS`）

三个自由度：`x`（横向）、`z`（纵深）、`y`（握点升降 = 屈膝/举拍）。**`y` 不是可选的补丁**——没有它，球到面高度和拍面的差只能靠 `z` 去凑，人会被拖到场外去「等球掉下来」。

| 常量 | 现值 | 不变量 |
|---|---|---|
| `speed` / `speedZ` | 4.8 / 3.6 | 一帧最多挪这么多，否则看起来是瞬移 |
| `speedY` | 9.0 | 屈膝/举拍比跑动快得多，但不能瞬间到位（会像镜头抖） |
| `deadband` | 0.05 | 小于它不动，避免贴球左右抖 |
| `maxX` | **3.9** | 单打边线 4.115，留 20cm 免得踩线。原来 3.0，够不着小斜线 |
| `minZ` / `maxZ` | **HIT_Z−3.0 / HIT_Z+1.0** | 前端放到网前 3m：短球会在 z≈−8 落地、z≈−1.4 二次落地判死，不往前迎就永远等不到。后端只到底线内 1m，再往后是「被球牵着退」 |
| `minGripY` / `maxGripY` | **0.70 / 1.65** | 深屈膝到举拍。低于 0.70 拍面到不了 0.70m 的贴网球；高于 1.65 拍面会出 HUD |
| `incomingVz` | 0.6 | 前进速度低于它不算「朝我来的球」。**别靠预测器返回 null 兜**，横向飘的球照样算得出穿面点 |
| `PAST_MARGIN` | 0.15 | 球越过拍面平面这么多就站住认了这一拍，不再回头追 |

## 6.1 几何 / 物理

- **`sweepFace` 的判据必须是盘形，不是穿平面**。掠射时球心不穿平面但球体压到拍线，按穿平面判会漏 = 穿模。
- **不能用点判定**，必须线段求交。高速球在两帧之间穿过拍面，两端都不在椭圆内。
- **`v × ω` 不能写成 `ω × v`**。写反上旋会往上飘，看着「也挺像那么回事」，但旋转玩法全废。单测钉了一条。
- **撞墙/撞网必须用碰撞事件判断**，不能用位置跨越。碰撞后位置被修正回墙外，`p[2] <= WALL_Z` 永远不成立。
- **静止球要提前返回**，否则每秒刷 240 个 ground 事件，音效和粒效被引爆。
- **`advance` 的 `onStep` 返回 `false` 必须 break**。球被接住后速度为 0，继续推进会往下掉一点，还可能重复触发碰撞。
- **顶点不能靠「球到拍面那一刻」代替**。球还在缓升时顶点在拍面之后 0.55–0.85m，`feedBounce` 的 sim 要 `passed` 之后继续跑到 `v[1] < 0`。
- **`sampleCrossings` 必须按「两次落地即判死」截断，且判据要和 `rally`/`duel` 同源**（`bounces >= 2 && at[2] > NET_Z`）。少了它，采样会推出一条「二次弹起后飘到击球面」的弹道——那条弹道在真实物理里不存在，规划器却会把人放在终点站着等。坑的形状是「走位看起来到了正确位置、球却凭空消失」，会误判成走位或判定 bug。注意计数要从 `ball.bounces` 起算：来球往往已经弹过一次，只数「从现在起」会数漏。

## 6.2 位姿与时序

- **球拍是「握点 + 朝向」，不是「拍面中心 + 朝向」**。后者屏幕上拍子只转不平移，玩家会立刻察觉不对。
- **凡是「拍面在哪」都用 `faceCenter(pose)`**，不要用 `pose.pos`。握点到中心差 0.6m。
- **渲染与判定必须用同一份 pose**。各算一份就是「看着碰到、判定说没有」。
- **不要用拍面中心的位移估走位速度**。那里面混着挥拍旋转（手腕一转 4 m/s），会把球瞄到半米外。
- **重瞄的目标不要写成「拍面中心 + 本球偏移」**。玩家跟着球挪半步会形成正反馈，球越推越远。
- **模拟器的挥拍时机不要用整条弹道外推**。来球中途还会落地弹一次，整条弹道外推会把那一拐算进去。用 `tta = (HIT_Z - z)/vz`。

## 6.3 测试与模拟器

- **模拟器里球拍必须真的会转**。改造前位姿全程同一个 Q，只有 omega 在变，于是「挥拍甩走拍面」这条真机主路径 0 覆盖——单测全绿、sim 30/30、真机全漏。现在绕**局部 x 轴**转，中心扫出 0.3–1.1m。绕法线转是不行的：中心不动，等于没测。
- **测试里的走位别用整条弹道外推**。拍面会跟着球走，走位再叠加预测会互相带偏，球到面时偏到盘外。走位要限速（0.07m/帧）且朝球的**当前**横向。
- **测试走位要用物理前推（`predictX`）**，不能用线性外推：落地会削掉 26% 横向速度。
- **偶发漏接要多种子复现**。发球 `vx` 随机，只在特定扰动耦合下出现。单种子跑过不代表没问题。
- **改发球节奏要放宽所有「等球到面」的测试窗口**。否则偶发失败，而且看起来像别的问题。
- **样本少的统计断言不要卡跨度**。4 球的甜区跨度会偶发红，改成「都在盘内 + 不是每球完全一样」。

## 6.4 类型与工具链

- **TS 闭包赋值会 narrowing 成 `never`**（`let x: T | null = null` 在回调里赋值，之后读出来是 never）。解法：包一层 reader 函数，或把状态装进对象 `const st = { n: 0 }`。
- **TS commonjs 产物的 `exports.x =` 可以 monkey-patch**。这是抓 sim 内部输入的神器（例如替换 `physics.liftOverNet` 记录每次击球的真实参数）。
- **四元数用半角**：`[0, cos(θ/2), sin(θ/2), 0]` 才能得到 θ 倾斜。写成 `cosθ` 会得到两倍角度。
- **Windows 下 `execFileSync('npx.cmd')` 会失败**，要直接调 `node_modules/typescript/bin/tsc`。
- **Node 的递归删除可能被安全拦截器挡住**，测试脚本改成不删目录、直接覆盖。

## 6.5 前端 / 环境

- **`hidden` 属性会被 `display:flex` 覆盖**，要 `[hidden]{display:none!important}`。
- **`.diag` 类名在大屏和手机端撞过**，大屏改用 `.linkpanel`。写新组件前先 grep 类名。
- **不能 `Torus + scale` 做椭圆拍框**，会压扁管截面。要采样点 → 曲线 → `TubeGeometry`。
- **拍线不能用浅色**，浅背景上会消失。
- **微信 WebView / 非 HTTPS 静默拦截传感器**，不报错，只是没有数据。
